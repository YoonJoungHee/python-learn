변수 이름 규칙 퀴즈

파이썬에서 변수 이름을 만들 때 지켜야 할 규칙을 확인하는 문제입니다.
OX 문제 4개 + 최종 정리 문제 1개, 총 5문제입니다.

📋 변수 이름 규칙 미리 보기
✅
영문자·숫자·밑줄(_) 사용 가능
name, age_1, my_score 모두 가능합니다.
❌
숫자로 시작 불가
1name, 3score 처럼 숫자가 맨 앞에 오면 안 됩니다.
❌
특수문자 사용 불가 (밑줄 제외)
my-name, my name, score! 처럼
공백·하이픈·느낌표 등은 사용할 수 없습니다.
🚫
예약어 사용 불가
if, for, while, print 같은
파이썬 예약어는 변수명으로 쓸 수 없습니다.
💡
대소문자 구분
score 와 Score 는 서로 다른 변수입니다.
💡
한글도 사용 가능 (권장하지 않음)
점수 처럼 한글도 기술적으로 사용 가능하지만
실무에서는 영문자를 권장합니다.
