🗂️ 자료형(Data Type)이란?

컴퓨터 프로그램은 자료(데이터)를 입력받아 처리하고 결과를 출력합니다. 이때 자료의 성격에 따라 분류해 놓은 것을 자료형(Data Type)이라 합니다. 파이썬에서는 자료형을 클래스(class)라고 부르기도 합니다.

💡 type() 함수어떤 자료의 자료형이 궁금할 때 type(자료)를 사용합니다. 자료형(class)을 반환합니다.

📝 문자열 — str

문자들의 모임으로, 작은따옴표(' ')나 큰따옴표(" ")로 감싸서 표현합니다.

  • 문자열끼리 + 로 이어붙일 수 있습니다. (연결)
  • 문자열에 숫자를 * 하면 반복됩니다. (반복)
  • str() 함수로 다른 자료형을 문자열로 변환할 수 있습니다.
${cb(`print("대한민국" + " Korea") # 문자열 연결 print('Dokdo' * 3) # 문자열 반복 print(type("3.74")) # print("475" + "123") # 숫자처럼 보여도 문자열!`)}

✏️ 실습 1 — 문자열 직접 입력해 보기

아래 코드를 보고 직접 입력한 후 실행해 보세요.

${cb(`print("시인은 '별'을 보며 잊혀진 이름을 불렀다.") # 큰따옴표 안에 작은따옴표 print("대한" + "민국") print(3 * "안녕하세요. ") print(type("컴퓨터과학"))`)} ${eb(0,``)}

🔢 정수형 — int

소수점이 없는 수입니다. 사칙연산이 가능하며, int() 함수로 다른 자료형을 정수형으로 변환할 수 있습니다.

${cb(`print(2371 + 1256) # 덧셈 print(2 ** 10) # 거듭제곱 print(473 % 10) # 나머지 print(type(29)) # print(int(3.14)) # 소수점 버림 → 3 print(int('2023')) # 문자열 → 정수`)}

✏️ 실습 2 — 정수형 직접 입력해 보기

${cb(`print(2371 + 1256) print(2 ** 10) print(473 % 10) print(type(29)) print(int(3.14)) print(int('2023'))`)} ${eb(1,``)}

🔣 실수형 — float

소수점이 있는 수입니다. float() 함수로 변환할 수 있습니다. 정수형과 메모리 저장 방식이 다르므로 명확히 구분해야 합니다.

${cb(`print(274 / 3) # 나누기 결과는 항상 float print(3.1415 * (2 ** 2)) # 실수 연산 print(float('2023')) # 문자열 → 실수 print(type(-245.2456)) # print(0.1 + 0.2) # 주의: 부동소수점 오차 발생!`)}
⚠️ 부동소수점 오차print(0.1 + 0.2) 를 실행하면 0.30000000000000004 가 나옵니다. 컴퓨터가 실수를 이진수로 저장하는 방식 때문에 생기는 현상입니다.

✏️ 실습 3 — 실수형 직접 입력해 보기

${cb(`print(274 / 3) print(3.1415 * (2 ** 2)) print(float('2023')) print(type(-245.2456)) print(0.1 + 0.2)`)} ${eb(2,``)}

✅ 불형 — bool

참(True)과 거짓(False)만 표현하는 자료형입니다. 조건문에서 매우 중요하게 쓰입니다.

  • True: 1이 아닌 수, 비어있지 않은 문자열
  • False: 0, 0.0, 빈 문자열 ""
${cb(`print(True) print(False) print(type(True)) # print(1 == 1) # True print(3 > 5) # False`)}

✏️ 실습 4 — 불형 직접 입력해 보기

${cb(`print(True) print(type(False)) print(1 == 1) print(3 > 5)`)} ${eb(3,``)}

➕ 복소수형 — complex (참고)

허수 기호 j를 사용해 복소수를 표현합니다. 고등 수학에서 배우는 개념으로, 파이썬에서 이런 자료형도 지원한다는 정도만 알아두세요.

${cb(`print(3 + 1j) # 복소수 print(type(3 + 1j)) # `)}
💡 리터럴(literal)프로그래밍 언어에서 사용하는 자료나 값 자체를 의미합니다.
'2026' → 문자열 리터럴  |  24 → 정수형 리터럴  |  3.14 → 실수형 리터럴  |  True → 불형 리터럴
