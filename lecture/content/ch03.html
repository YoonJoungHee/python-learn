📺 print() 함수

화면에 값을 출력하는 함수입니다. 괄호 안에 출력할 내용을 넣으면 됩니다.

${cb(`print("안녕하세요!") # 문자열 출력 print(2025) # 숫자 출력 print(3 + 7) # 계산 결과 출력 print(True) # 불형 출력`)}

📌 쉼표(,)로 여러 값 출력

쉼표로 구분하면 여러 값을 한 줄에 출력할 수 있습니다. 기본적으로 값 사이에 공백이 삽입됩니다.

${cb(`name = "홍길동" age = 17 print(name, age) # 홍길동 17 print(name, age, "살") # 홍길동 17 살`)}

📌 sep — 구분자 변경

sep 옵션으로 값 사이의 구분 문자를 바꿀 수 있습니다. 기본값은 공백(" ")입니다.

${cb(`print("2026", "03", "02", sep="-") # 2026-03-02 print("a", "b", "c", sep=", ") # a, b, c print("010", "1234", "5678", sep="-")# 010-1234-5678`)}

📌 end — 줄바꿈 변경

print()는 기본적으로 출력 후 줄을 바꿉니다. end 옵션으로 줄바꿈 대신 다른 문자를 넣을 수 있습니다.

${cb(`print("안녕", end="") # 줄바꿈 없음 print("하세요!") # 바로 이어서 출력 print("A", "B", "C", sep="-", end="!\n") # A-B-C!`)}

📌 이스케이프 문자

문자열 안에서 특수한 효과를 내는 문자입니다.

코드 의미 예시
\n줄바꿈print("강아지\n고양이")
\t탭(들여쓰기)print("이름\t나이")
\' \"따옴표 출력print("He said \"Hi\"")

✏️ 실습 1 — 다양한 print() 옵션 입력해 보기

${cb(`print("강아지\n고양이") print("이름", "나이", sep="\t") print("2026", "1", "1", sep="/")`)} ${eb(0,``)}

📌 f-string — 변수를 문자열에 넣기

문자열 앞에 f를 붙이고 {변수명}을 쓰면 변수 값이 그 자리에 들어갑니다. 가장 많이 쓰이는 출력 방식입니다.

${cb(`name = "홍길동" age = 17 score = 95.5 print(f"이름: {name}, 나이: {age}살") print(f"점수: {score:.1f}점") # 소수점 1자리`)}

✏️ 실습 2 — f-string 직접 입력해 보기

${cb(`subject = "정보" score = 98 print(f"과목: {subject}") print(f"점수: {score}점")`)} ${eb(1,``)}
