🔍 비교 연산자

두 값을 비교하여 True 또는 False를 반환합니다.

연산자 의미 예시 결과
==같다5 == 5True
!=같지 않다5 != 3True
>크다5 > 3True
<작다5 < 3False
>=크거나 같다5 >= 5True
<=작거나 같다3 <= 5True
⚠️ = 와 == 의 차이= 는 값을 저장하는 대입 연산자, == 는 값을 비교하는 연산자입니다.

✏️ 실습 1 — 비교 연산자 직접 입력해 보기

print(10 == 10)
print(10 != 5)
print(3 > 7)
print(5 >= 5)
print(type(10 > 5))

🔗 논리 연산자

여러 조건을 조합할 때 사용합니다.

연산자 의미 예시 결과
and둘 다 참일 때 TrueTrue and FalseFalse
or하나라도 참이면 TrueTrue or FalseTrue
not참↔거짓 반전not TrueFalse
 
age = 17
score = 85
print(age >= 18 and score >= 80)   # False
print(age >= 18 or score >= 80)    # True
print(not (age >= 18))             # True

✏️ 실습 2 — 논리 연산자 직접 입력해 보기

x = 15
print(x > 10 and x < 20)
print(x < 5 or x > 10)
print(not (x == 15))
