변수란?

변수는 데이터를 저장하는 이름표가 붙은 상자입니다. 값을 넣어두고 나중에 꺼내 쓸 수 있습니다.

${cb(`name = "김철수" # 문자열(str) age = 17 # 정수(int) height = 172.5 # 실수(float) is_student = True # 논리값(bool) print(name, age, height, is_student)`)}

자료형 4가지

  • int — 정수: 17, -3, 0
  • float — 실수: 3.14, -0.5
  • str — 문자열: "안녕", 'Python'
  • bool — 논리값: True, False

type()으로 자료형 확인

${cb(`x = 42 print(type(x)) # y = "안녕" print(type(y)) # `)}
⚠️ 주의변수 이름은 숫자로 시작할 수 없습니다.
${eb(1,`name = "나의이름" age = 0 hobby = "취미" print("이름:", name) print("나이:", age) print("자료형:", type(age))`)}
