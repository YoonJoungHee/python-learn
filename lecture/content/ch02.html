📦 변수(Variable)란?

변수는 데이터를 저장하는 이름표가 붙은 상자입니다. 값을 넣어두고 나중에 꺼내 쓸 수 있습니다. = 기호로 값을 저장합니다.

name = "홍길동"     # 변수 name에 문자열 저장
age = 17            # 변수 age에 정수 저장
height = 172.5      # 변수 height에 실수 저장
print(name, age, height)
💡 변수 이름 규칙 · 영문자, 숫자, 밑줄(_)만 사용 가능
· 숫자로 시작할 수 없음 (예: 1name ❌)
· 대소문자 구분 (age ≠ Age)
· 파이썬 예약어 사용 불가 (if, for, True 등)

🔢 산술 연산자

변수에 저장된 값으로 다양한 연산을 할 수 있습니다.

연산자 의미 예시 결과
+더하기10 + 313
-빼기10 - 37
*곱하기10 * 330
**거듭제곱2 ** 101024
/나누기 (실수)10 / 33.333...
//몫 (정수)10 // 33
%나머지10 % 31

✏️ 실습 2 — 변수와 연산자 함께 사용해 보기

아래 코드를 직접 입력하고 실행해 보세요.

a = 10
b = 3
print(a + b)
print(a ** b)
print(a // b)
print(a % b)

🔄 복합 대입 연산자

변수의 값을 바꿀 때 자주 사용하는 축약 표현입니다.

score = 100
score = score + 10   # 기본 방식
score += 10          # 축약 방식 (같은 의미)
score -= 5           # score = score - 5
score *= 2           # score = score * 2
print(score)
