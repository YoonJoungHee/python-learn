🔁 반복문 — for

정해진 횟수만큼 또는 순서가 있는 자료를 하나씩 꺼내면서 반복합니다.

for 변수 in 반복할대상:
    # 반복할 코드
# 리스트의 요소를 하나씩 출력
fruits = ["사과", "바나나", "딸기"]
for fruit in fruits:
    print(fruit)

📌 range() — 숫자 범위 반복

range()로 반복 횟수를 지정할 수 있습니다.

형태 의미 생성되는 수
range(n)0부터 n-1까지0, 1, 2, ..., n-1
range(a, b)a부터 b-1까지a, a+1, ..., b-1
range(a, b, c)a부터 b-1까지 c씩 증가a, a+c, a+2c, ...
 
for i in range(5):          # 0, 1, 2, 3, 4
    print(i, end=" ")
print()

for i in range(1, 6):      # 1, 2, 3, 4, 5
    print(i, end=" ")
print()

for i in range(0, 10, 2):  # 0, 2, 4, 6, 8
    print(i, end=" ")

✏️ 실습 1 — for 반복문 직접 입력해 보기

for i in range(1, 6):
    print(f"{i}번째 반복")

🔁 반복문 — while

조건이 참인 동안 계속 반복합니다. 반복 횟수가 정해지지 않았을 때 주로 사용합니다.

while 조건:
    # 조건이 True인 동안 반복
count = 1
while count <= 5:
    print(f"count = {count}")
    count += 1          # 이 줄이 없으면 무한루프!
⚠️ 무한루프 주의!while 안에서 조건을 변화시키지 않으면 프로그램이 영원히 멈추지 않습니다. 반드시 탈출 조건을 만들어 주세요.

✏️ 실습 2 — while 반복문 직접 입력해 보기

total = 0
i = 1
while i <= 10:
    total += i
    i += 1
print(f"1부터 10까지의 합: {total}")

📌 break와 continue

break는 반복을 즉시 종료하고, continue는 현재 반복을 건너뛰고 다음으로 넘어갑니다.

# break: 3을 만나면 멈추기
for i in range(1, 6):
    if i == 3:
        break
    print(i, end=" ")   # 1 2

print()

# continue: 짝수만 건너뛰기
for i in range(1, 6):
    if i % 2 == 0:
        continue
    print(i, end=" ")   # 1 3 5

✏️ 실습 3 — break와 continue 직접 입력해 보기

for i in range(1, 11):
    if i % 2 == 0:
        continue
    print(i, end=" ")   # 홀수만 출력
