🔀 선택문(조건문) — if

조건에 따라 다른 코드를 실행합니다. 파이썬에서는 들여쓰기(4칸 또는 탭)로 코드 블록을 구분합니다.

score = 85
if score >= 60:
    print("합격!")
else:
    print("불합격")
⚠️ 들여쓰기 필수!들여쓰기가 없거나 일관되지 않으면 오류가 발생합니다.

✏️ 실습 1 — if~else 직접 입력해 보기

score = 75
if score >= 60:
    print("합격!")
else:
    print("불합격")

📌 if ~ elif ~ else

조건이 여러 개일 때 elif를 사용합니다. 위에서부터 순서대로 확인하고, 처음으로 참인 조건만 실행합니다.

score = 78
if score >= 90:
    print("A 등급")
elif score >= 80:
    print("B 등급")
elif score >= 70:
    print("C 등급")
else:
    print("D 등급")

✏️ 실습 2 — 등급 판별 직접 입력해 보기

score = 78
if score >= 90:
    print("A 등급")
elif score >= 80:
    print("B 등급")
elif score >= 70:
    print("C 등급")
else:
    print("D 등급")

📌 중첩 if

age = 20
has_id = True
if age >= 18:
    if has_id:
        print("입장 가능")
    else:
        print("신분증 필요")
else:
    print("미성년자 입장 불가")

✏️ 실습 3 — 홀수/짝수 판별기

num = 7
if num % 2 == 0:
    print(f"{num}은(는) 짝수입니다.")
else:
    print(f"{num}은(는) 홀수입니다.")
