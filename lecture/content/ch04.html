⌨️ input() 함수

사용자로부터 키보드 입력을 받는 함수입니다. 입력받은 값은 항상 문자열(str)로 저장됩니다.

${cb(`name = input("이름을 입력하세요: ") print("안녕하세요,", name)`)}
⚠️ input()의 결과는 항상 str!숫자를 입력해도 문자열로 저장됩니다. 숫자로 계산하려면 반드시 형 변환이 필요합니다.

🔄 자료형 변환 — int(), float()

input()으로 받은 값을 숫자로 쓰려면 int() 또는 float()으로 변환해야 합니다.

${cb(`age = int(input("나이를 입력하세요: ")) print(age + 1, "살이 되겠네요!") height = float(input("키를 입력하세요(cm): ")) print(f"키: {height}cm")`)}

✏️ 실습 1 — 두 수를 입력받아 합 구하기

아래 코드를 보고 직접 입력한 후 실행해 보세요.

${cb(`a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) print(f"{a} + {b} = {a + b}")`)} ${eb(0,``)}

📌 한 줄에 여러 값 입력 — split()

공백으로 구분된 여러 값을 한 번에 입력받을 때 split()을 사용합니다.

${cb(`a, b = input("두 수 입력: ").split() a = int(a) b = int(b) print(f"합: {a + b}, 차: {a - b}")`)}
💡 map()으로 더 간결하게 ${cb(`a, b = map(int, input("두 수 입력: ").split()) print(a + b)`)}
